# Local placeholder photos

Drop `.jpg` or `.png` files named after a sample profile id (`sample-1.jpg`, `sample-2.png` and so on, as listed in `packages/shared/src/discovery.ts`). The discovery deck shows each photo on that card instead of the initials avatar.

Everything in this folder except this README is gitignored, because the repository is public. Commit a photo only with the consent of the person in it.
